Which files to download, and where

Menu names change often. If a menu is not where this guide says, search the help page inside your seller panel for the report name. Items marked (check) were not confirmed from an official page, so verify them in your own panel.

Before you start

  • Download reports for the same date range on every platform.
  • Download in CSV or XLSX if you have the choice.
  • Do not edit the files. Upload them exactly as downloaded.
  • Best time to download a month: 3 to 4 weeks after the month ends, so most returns and settlements have arrived. You can also download earlier for a running-month view; the app labels those numbers as provisional.

Monthly upload checklist

  1. Orders report for the period, for each platform.
  2. All settlement or payout files issued in the period, for each platform (and any held-money report, such as Amazon's Deferred transactions).
  3. Returns / RTO report for the period, plus the next month's if available.
  4. Ads report for the period.
  5. Updated cost sheet for any new or repriced SKU.
  6. Bank statement for the period (optional).

Common mistakes

  • Uploading only part of a multi-sheet file (especially Flipkart payouts).
  • Using different date ranges across reports.
  • Forgetting to upload returns next month, which makes the old month look better than it is.
  • Editing or re-saving the file in a way that changes column headers or dates.
  • Missing cost for new SKUs. The app shows a warning with the amount of profit at risk.
